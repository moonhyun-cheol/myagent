# 블랙잭 웹 게임

외부 라이브러리 없이 HTML, CSS, JavaScript로 만든 단일 플레이어 블랙잭 게임입니다.

## 실행 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다.
2. **게임 시작**을 누릅니다.
3. 카드가 더 필요하면 **히트**, 현재 점수로 승부하려면 **스탠드**를 누릅니다.

## 규칙

- 목표는 21점을 넘지 않으면서 딜러보다 높은 점수를 만드는 것입니다.
- A는 11점으로 계산되며, 21점을 넘을 경우 자동으로 1점으로 바뀝니다.
- 딜러는 17점 이상이 될 때까지 카드를 받습니다.
- 시작 카드 두 장이 21점이면 블랙잭입니다.

## 검증

Node.js가 설치되어 있다면 아래 명령으로 JavaScript 문법을 확인할 수 있습니다.

```powershell
npm run check
```
