# llama.cpp runtime (optional)

Place Windows binaries here for deep model verification and local inference (Phase 4+):

- `llama-server.exe`
- required DLLs (`ggml-*.dll`, etc.)

Download from [llama.cpp releases](https://github.com/ggerganov/llama.cpp/releases) or build locally.

Without this folder, MY Agent still scans GGUF files and performs magic-byte verification.
