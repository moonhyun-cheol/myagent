# 세션 통합 수정계획 · 2026-09-17

기존 첨부 유지 수정은 보존한다. 설치 배포·버전 증가·게시·대화 데이터 삭제는 이번 작업에 포함하지 않는다.

| 순서 | 이슈 | 수정 및 완료 기준 |
|---|---|---|
| 1 | 대화 소속과 작업 폴더 | 연결/해제는 대화를 이동하지 않는다. 명시 연결과 기존 상속을 구분한다. 기억·모델은 대화 소속을 유지하며 실행 루트와 UI가 일치한다. 비동기 이동 경합을 검사한다. |
| 2 | 응답·작업 접힘 | 응답 기본 펼침, 작업 기본 접힘. 진행·완료가 수동 선택을 덮어쓰지 않는다. 대화/턴별 선택을 복원한다. |
| 3 | 오른쪽 패널 | 명확한 접기/복원 진입점, 열림 상태 저장. 숨겨도 자식 상태를 보존한다. |
| 4 | 시각 계층 | 메인 탭 밑줄, 보조 탭 중립 강조, 0 배지 숨김, 작업 폴더 라벨, 간결한 빈 상태. 입력창·첨부 카드의 테두리와 크기를 정리한다. |
| 5 | 드롭 | 동일 이름·크기·시간의 서로 다른 파일을 제거하지 않는다. 드롭 오버레이와 다중 첨부를 검사한다. |
| 6 | 긴 대화 성능 | 경과시간 갱신을 별도 컴포넌트로 분리하고 반복 검색·Markdown 콜백을 안정화한다. 100/500/1000개 대화를 계측한다. 부족하면 가상화·페이지 로딩은 후속 작업으로 남긴다. |
| 7 | 미전송 첨부 유지 | 기존 대화별 초안, 썸네일, 업로드 중 이동·삭제·전송·큐 경합 브라우저 회귀검사. 앱 재시작 영속성은 별도 범위다. |

## 검증 계획
- Core/UI TypeScript 검사.
- 임시 저장소에서 연결·해제·상속·기억·모델·승인 경계 검사. 사용자 데이터에 쓰지 않는다.
- 격리 Chromium에서 실제 React 구성요소를 실행하여 접힘·진행/완료·재진입·패널·드롭·첨부 회귀검사.
- 긴 대화의 합성 계측은 실제 설치 앱의 성능 보장으로 표현하지 않는다.
- Windows 탐색기 → 설치 앱 WebView2 실제 드롭은 별도 검증 필요. 가상 DataTransfer 검사만으로 완료 처리하지 않는다.

## 결과
- 구현 완료: 대화 소속과 실행 작업 폴더를 분리하고, 명시적 연결 해제·기존 기록 상속·비동기 저장 경합을 처리했다.
- 구현 완료: 응답은 기본 펼침, 작업은 기본 접힘이며 사용자의 선택을 진행/완료 및 대화 재진입 후에도 턴 ID 기준으로 복원한다.
- 구현 완료: 오른쪽 패널 접기/복원과 열림 상태 저장, 패널/입력창/첨부/작업 목록의 시각 계층 정리, 동명 다중 드롭 보존, 긴 대화의 반복 계산·타이머 범위 축소를 반영했다.
- 회귀검사 통과: 작업 폴더 소속/연결/해제/승인 경계, 미전송 첨부 A→B→A·업로드/삭제/전송 경합, 패널 640/1000/1440px 접기·복원·상태 유지, 접힘 기본값·완료 전환·재진입.
- 합성 Chromium 계측(실제 ChatPane): 100턴 104ms, 500턴 320ms, 1000턴 617ms. 모든 말풍선 렌더를 확인했으며 설치 앱 성능 보장은 아니다.
- 정적 검사: Core 및 UI TypeScript 검사 통과.

## 남은 실환경 확인
- Windows 탐색기에서 설치 앱 WebView2로 동일 이름 파일을 직접 다중 드롭하는 경로.
- 설치 앱 종료·재시작 후 미전송 첨부 복원은 이번 범위가 아니며, 현재 보존 범위는 실행 중 대화 이동이다.
- 설치 앱 빌드·배포·버전 증가는 수행하지 않았다.
