# SSH 서버에 연결하기

SSH는 다른 컴퓨터에 안전하게 로그인해 그곳에서 명령을 실행하는 방법입니다. **설정 → SSH 서버**가 보이지 않으면 설정에서 **서버 열기**를 검색하세요.

| 어떤 서버인가요? | 어떤 길을 쓰나요? |
|---|---|
| MY Agent를 설치할 수 있는 Windows PC | 서버 PC에서 **이 PC 서버**를 열고, 접속할 PC에는 연결 코드만 보냅니다. |
| 팀원이 쓸 리눅스·맥·NAS·클라우드 서버 | 서버 관리자가 직접 등록한 뒤 **팀원 초대**를 씁니다. 팀원에게 관리자 키를 주지 않습니다. |
| 내가 관리하는 기존 SSH 서버 | **서버 추가 → 직접 입력**에서 내 계정으로 등록합니다. |

### 이 PC 서버: 3단계
1. 서버 PC에서 **이 PC 서버**의 경고를 읽고 **서버 열기**를 누르세요. 연결된 기기는 이 Windows 계정과 같은 권한을 가지며 시작 폴더 밖에도 접근할 수 있습니다. 내 PC는 내 기기만, 공용 PC는 공용 계정으로 쓰세요.
2. 방화벽과 사내망 연결을 확인하고 **연결 코드 만들기 → 복사**를 누르세요. 10분·1회용입니다. 원하면 **MY Agent가 켜질 때 자동으로 열기**를 켜세요.
3. 받을 PC의 **서버 추가**에 붙여 넣고 **연결**하세요. 작업 폴더가 연결된 Agent 대화에서 서버·폴더·명령을 읽고 직접 승인하세요. 서버 PC에서는 **연결된 기기**에서 끊을 수 있습니다.

### 팀원 초대: 4단계
1. 팀원은 **서버 추가 → 팀원 초대 받기 · 내 열쇠 코드**에서 내 코드를 서버 관리자에게 보냅니다. 이 코드에는 공개 열쇠만 들어 있습니다.
2. 서버 관리자는 직접 등록하고 지문을 확인한 서버의 **팀원 초대**에서 코드를 읽습니다. 기기 이름과 지문 끝 6자리를 팀원과 별도 경로로 맞추고 **팀원용 서버 계정**을 입력합니다. 예를 들어 IT가 최소 권한 계정 `team-minji`를 미리 만들어 둘 수 있습니다. 운영자 계정은 쓰지 마세요.
3. 관리자는 **서버에 넣을 명령 복사**를 누르고, 서버나 클라우드 웹 콘솔에서 **그 팀원용 계정으로** 직접 실행합니다. **넣었습니다 → 초대 코드 만들기**를 눌러 해당 팀원에게 보냅니다.
4. 팀원은 **서버 추가**에 초대 코드를 붙여 넣습니다. 권한을 뺄 때는 관리자가 **초대한 팀원 → 빼는 명령 복사** 후 같은 계정으로 직접 실행합니다. 목록에서 기록만 지워서는 권한이 사라지지 않습니다. 열쇠를 빼면 새 로그인은 거부됩니다. 이미 열린 접속을 즉시 끊어야 하면 관리자가 해당 세션도 종료하세요.

### 내 서버 직접 추가
서버 종류, 주소, 계정과 본인 인증 수단을 넣고 **등록하고 연결 준비**를 누르세요. **지문 확인 방법**의 명령은 해당 서버나 서비스 웹 콘솔의 브라우저 터미널에서 실행합니다. 표시된 지문이 같을 때만 확인하세요. 클라우드 키 파일은 본인만 쓰세요. 팀원에게 파일이나 비밀번호를 보내지 마세요.

### 안전 수칙
연결 코드는 받을 사람에게만 보내세요. 비밀번호나 키 파일을 돌려 쓰지 말고, 쓰지 않는 기기는 서버에서 끊으세요. 앱이나 AI가 외부 서버의 열쇠를 대신 넣거나 빼지 않습니다.

| 안 될 때 | 먼저 확인할 것 |
|---|---|
| 서버를 찾지 못함 | 두 PC가 같은 사내망 또는 같은 Tailscale에 있는지와 방화벽의 앱·네트워크 허용을 확인하세요. 임의로 인터넷에 포트를 열지 마세요. |
| PC가 절전 중 | 서버 PC를 깨운 뒤 다시 시도하세요. |
| 창을 닫고 연결이 끊김 | 일반 설정에서 **종료 시 트레이에서 계속 실행**을 켜세요. 재부팅했다면 앱을 실행하세요. |
| 주소나 포트가 바뀜 | 서버에서 새 코드를 받아 연결 목록의 **새 코드로 주소 갱신**에 넣으세요. |
| 코드가 만료되거나 이미 사용됨 | 새 연결 코드를 받으세요. 새로 만들면 이전 코드는 쓸 수 없습니다. |
| 팀원 열쇠를 거부함 | 관리자가 올바른 팀원 계정에 열쇠 한 줄을 넣었는지 확인한 뒤 **연결 다시 확인**을 누르세요. |
| NAS가 응답하지 않음 | NAS 관리자가 SSH를 켰는지, 포트와 팀원용 계정이 맞는지 확인하세요. |

회사 밖에서 이 PC 서버를 쓰려면 두 PC 모두 회사가 허용한 Tailscale에 연결하세요. 클라우드 계정으로 접속하는 방식은 다음 버전(v2) 계획이며 현재 제공하지 않습니다.
