# 고전환 랜딩 페이지 — 구조·카피·전략

랜딩 페이지는 홈페이지가 아닙니다. 홈페이지는 여러 의도를 담고, 랜딩 페이지는 **하나의 제안 → 하나의 오디언스 → 하나의 주요 행동**에 집중합니다.

## 사전 수집 (없으면 질문)

### 1) 페이지 목적
- **유일한 주요 행동**은? (체험, 데모, 구매, 웨이트리스트, 다운로드)
- **제안**은 정확히 무엇인가?
- **전환**의 정의는? (클릭, 가입, 결제)

### 2) 오디언스·맥락
- ICP(이상적 고객)는 누구인가?
- 해결하려는 문제는?
- 전환을 막는 상위 3가지 반론
- 유입 경로: 광고 / 검색 / SNS / 이메일
- 방문 시점에 이미 알고 있는 정보

### 3) 증거·자산
- 로고, 후기, 수치, 사례
- 스크린샷, 데모 영상, GIF
- 환불·취소·보장 조건

### 4) 제약
- 브랜드 톤: 캐주얼 vs 프로페셔널
- 디자인 방향: 미니멀 에디토리얼 / 플레이풀 3D / 글래스 UI
- 모바일 우선 여부

---

## 핵심 구조

### Above the fold (필수)
1. **헤드라인** — 결과 + 오디언스
2. **서브헤드라인** — 방법·구체성
3. **주요 CTA** — 동사 + 얻는 것
4. **증거 1개** — 로고 스트립 / 수치 / 짧은 후기
5. **히어로 비주얼** — 제품 스크린샷 또는 일러스트

### Mid page (설득)
6. **문제 → 해결** (1섹션)
7. **혜택** (3–5개, 결과 중심)
8. **작동 방식** (3단계)
9. **사회적 증거** (후기/사례)

### Bottom (반론 처리)
10. **FAQ** (6–12 Q/A)
11. **리스크 완화** (무료 체험, 언제든 취소, 환불 보장)
12. **최종 CTA** (상단과 동일)

## 레이아웃 유형

| 유형 | 적합한 경우 |
|------|------------|
| **A) 클래식 히어로 + 섹션** | 히어로 스크린샷으로 제품이 바로 이해될 때 |
| **B) 롱폼 스토리** | 교육·설득이 길게 필요할 때 |
| **C) 미니멀 전환** | 이메일 등 고의도 트래픽, 짧은 제안 |
| **D) 비교 랜딩** | "X vs Y", "best for…" 검색 의도 |

---

## 고전환 전략

1. **유입 메시지와 히어로 일치** — 광고 헤드라인을 히어로에 반영
2. **다음 단계 명확히** — 폴드 위 CTA는 하나만
3. **혜택 우선** — 기능이 아니라 사용자에게 의미
4. **구체성** — ❌ "시간 절약" → ✅ "주간 보고 4시간 → 15분"
5. **리스크 감소** — 무료 체험, 카드 불필요, 취소 가능, 환불 중 하나 이상
6. **FAQ는 푸터가 아님** — 마찰이 큰 제안은 FAQ를 앞쪽에

## 카피 템플릿

### 헤드라인
- "{결과} without {고통}"
- "{카테고리} for {오디언스}"
- "{시간} 안에 {결과} 출시"

### CTA (약한 표현 금지)
- ✅ "무료 체험 시작" / "데모 예약" / "체크리스트 받기"
- ❌ "자세히 보기" / "제출"

### 혜택 불릿
- **혜택** — 근거/수치

---

## 섹션 작업 순서

1. Hero → 2. Benefits → 3. How it works → 4. Proof → 5. FAQ → 6. Final CTA

매번 전체 페이지를 다시 만들지 말고 **섹션 단위로 반복**합니다.

---

## SEO·AEO (해당 시)

- 광고 전용·단기 캠페인 → `noindex` 검토
- 에버그린·검색 의도 일치 → title/meta, FAQ 평문 Q/A, 내부 링크

---

## 흔한 실수

- 폴드 위 CTA 과다
- 모호한 가치 제안 ("streamline", "optimize")
- 결과 없는 기능 나열
- 증거가 페이지 하단에만 있음
- 모바일 가독성 붕괴
