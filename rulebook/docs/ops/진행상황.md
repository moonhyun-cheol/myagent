## 과제 체크

| # | 과제 | 상태 | 메모 |
|---|------|------|------|
| 1 | 채팅으로 폴더에 파일 만들고 고치기 | 완료 | 디스크에 없으면 완료 불가 |
| 2 | `edit_file` 실패 무한 반복 끊기 | 완료 | 같은 파일 2회 실패 후 전체 다시 쓰기 |
| 3 | Windows에서 만든 서버·테스트가 살아 있게 | 완료 | 서버 진입점·`npm test` 파일 경로·브라우저 import 규칙을 시험에 고정 |
| 4 | 빈 폴더에서 미니앱 한 방에 만들기 | 부분 | 결국 성공. 검사 스크립트가 여러 턴 힌트 준 뒤. 힌트 없이 N회는 안 함 |
| 5 | 외부 코딩 sidecar 실실행 | 제외 | 코딩 변경은 Responses 연속성·승인·검증을 유지하는 내장 에이전트로 단일화 |
| 6 | 레포 알아보기 (BAT·README) | 완료 | 한글 별칭 삭제, README 입구·이 문서 |
| 7 | 조직 전용 시장조사 분리 | 완료 | neutral core에서 제거하고 독립 모듈 업데이트 경계로 전환 |
| 8 | 조직 자동화 | 선택 | 서명된 조직 모듈이 등록한 도구만 실행 |

상태: **완료** / **부분** / **미완**

다음에: 4(힌트 없이 N회) → 5

## 설치법

**직원 PC (zip)**  
압축 해제 → `install.bat` → 설치 폴더 선택 → `MYAgent.exe`
라이선스는 첫 실행 때 활성화 서버에서 받거나, 수동 복구 시 `tools\commands\setup-vault.bat`

**개발 PC (git)**  
Node 22+, WebView2

```
npm install
npm run build
npm run build:exe
copy data\vault\license.ocx.example data\vault\license.ocx
MYAgent.exe
```

업데이트: 설치 폴더에 delta zip 두고 `UPDATE.bat` (`data/`는 유지)

## 각 기능

| 기능 | 하는 일 |
|------|---------|
| 채팅 | 창에서 대화. 기록은 `data/sessions/` |
| 코드 에이전트 | 지정 폴더의 파일을 읽고 쓰고, 명령 실행 |
| 첨부 | PDF/DOCX/이미지/영상(키프레임) |
| 브라우저 | 페이지 열고 클릭·스크린샷 (Playwright) |
| 모델 | 사용자 구성 provider, API 키, 선택적 로컬 GGUF |
| 조직 전용 기능 | 별도 서명 모듈에서 설치·업데이트 |
| 플러그인 | 설치 후 로컬 도구 추가 |
| 라이선스 | 기능 잠금. 서버 `:10201` |
| 코딩 실행 | 내장 에이전트가 수정·승인·검증을 한 런타임에서 수행 |

화면 코드는 `ui/workspace/`만. 창은 `shell/`, 서버는 `core/`.

## 기능 실행에서의 오류

| 어디서 | 증상 | 원인 |
|--------|------|------|
| 코드 에이전트 | “완료”인데 파일 없음 | 말만 하고 디스크 미반영 |
| 코드 에이전트 | 같은 수정 무한 반복 | `edit_file` 실패를 성공으로 오해 |
| 코드 에이전트 → 만든 서버 | Windows에서 포트 안 열림 | ESM “이 파일이 메인인지” 경로 비교 실패 |
| 코드 에이전트 → `npm test` | 테스트 러너 실패 | `node --test test/` (폴더) 가 Node 22+ Windows에서 깨짐 |
| 코드 에이전트 → 브라우저 JS | 버튼/저장 안 됨 | `public/*.js`가 `../src`를 import (번들 없음) |
| 빈 폴더에 앱 만들기 | 한 번에 안 끝남 | 검사 스크립트가 빠진 걸 여러 턴 다시 알려줘야 통과 |
| 사이드카 | 도구 호출해도 작업 안 함 | 프로그램 미설치. 거절만 됨 |
| 시장조사 | venv 없으면 파이프라인 실패 | `npm run market:bootstrap`. 실검색은 LLM·검색 키 |
| Discord (OpenClaw) | 원격 실행 안 확인 | 실기 안 돌림 (테스트 skip) |
| 클론만 | 창 안 뜸 | `npm run build` / 라이선스 없음 |

## 수정안

| 오류 | 이미 한 것 | 남은 것 |
|------|------------|---------|
| 거짓 완료 | 파일·테스트 증거 없으면 완료 불가 | 실사용에서 구멍 나는지 추가 확인 |
| edit 반복 | 같은 파일 실패 2회 후 중단, 전체 다시 쓰기 유도 | — |
| 서버 안 뜸 | 만드는 서버에 `import.meta.main` / `pathToFileURL` 요구 | 빈 폴더 시험을 **힌트 없이** 여러 번 |
| npm test | `test` 스크립트를 파일 경로로 고정 | 위와 같음 |
| 브라우저 import | `public/app.js`의 `../src` import 금지 | 위와 같음 |
| 코딩 실행 | 내장 도구 루프 등록 | 외부 코딩 sidecar 없이 실제 수정·검증 |
| 시장조사 | 폴더 내장 + bootstrap 명령 | 키 있는 PC에서 실검색 1회 |
| Discord | — | 실기 |

관련 코드: `core/src/agent/agent-outcome-gate.ts`, `tool-loop-guard.ts`, `core/src/sidecars/`, `tools/lab/agent-only-maxstress.mjs`

## 업무 명령 추가 (CQR → Adapter → 놉스 쪽지)

새 명령을 넣을 때 오케스트레이터를 분기하지 않는다. 세 곳에 같이 적는다.

1. `core/config/defaults/automaton-tools.manifest.json`
2. `core/src/automaton/openclaw-workflow-map.ts` (`command_id`)
3. `core/src/router/unified-intent-catalog.ts` (manifest를 읽으므로 보통 1만 추가하면 따라옴. routing.json에도 도구가 있으면 같이)

슬래시·자연어·백그라운드 접수·쪽지(본문 NAS UNC + 파일 첨부)는 같은 파이프다. Discord Gate는 유지. 놉스 입구 `/nops/adapter/request`는 아직 구현하지 않음.
