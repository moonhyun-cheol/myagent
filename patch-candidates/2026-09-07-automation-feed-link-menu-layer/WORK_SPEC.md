# 자동화 실행결과 링크 및 작업 메뉴 레이어 개선

## 목적

- 자동화 사이드바 실행결과를 긴 본문/첨부 미리보기 대신 작업명 중심의 간단한 링크로 표시한다.
- 항목 클릭 시 작업 뉴스피드 모달을 열고 해당 피드 카드로 이동해 강조한다.
- 자동화 작업 행의 더보기 메뉴가 아래 컨테이너에 가려지지 않도록 표시 방향과 레이어를 보정한다.
- 기존 `즉시 실행` 메뉴를 유지하고 접근 가능하게 한다.

## 변경 범위

- `ui/workspace/src/components/GeminiNavSidebar.tsx`
  - 사이드바 피드 항목을 작업명 링크 형태로 축약
  - 선택한 피드 ID를 뉴스피드 모달로 전달
- `ui/workspace/src/components/AutomationFeedModal.tsx`
  - 대상 피드 ID를 받아 전체 필터로 전환
  - 해당 카드로 스크롤 및 포커스하고 강조선 표시
- `ui/workspace/src/components/SchedulerSurface.tsx`
  - 작업 행 메뉴를 위쪽으로 열고 z-index를 높여 clipping 방지

## 수용 기준

1. 사이드바에는 각 실행 결과의 상태, 시각, 작업명만 간결하게 보인다.
2. 사이드바 항목 클릭 시 뉴스피드 모달이 열리고 동일 ID의 카드가 중앙으로 이동 및 강조된다.
3. 작업 행의 더보기 메뉴가 카드 하단이나 다음 영역에 잘리지 않는다.
4. 메뉴에서 `즉시 실행`을 선택할 수 있다.
5. UI 진단 및 관련 테스트가 통과한다.
